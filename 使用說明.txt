 系統架構
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  [FastAPI 後端]  python api_main.py       → http://localhost:8000
  [前端介面]      npm run dev              → http://localhost:3000
  [Claude 分析]   Claude Code 開著即可     → 排程自動執行

  資料流向：
  api_main.py（掃描 + K 線圖生成）→ scan_results/tw_日期.json
                                      ↓
  Claude Code（分析，17:00/21:20）  → scan_results/claude_tw_日期.json
                                      ↓
  API /api/scanner/results            → 合併兩份，回傳前端
                                      ↓
  前端 /scanner 頁                    → 展開個股：
                                          左：Claude 分析
                                          右：K 線圖

  外網架構（Cloudflare Tunnel）：
  手機/外部裝置
    → Cloudflare Tunnel（https://xxxx.trycloudflare.com）
    → Next.js（port 3000）← 只需暴露這一個 port
    → Next.js rewrite proxy（/api/* → localhost:8000）
    → FastAPI（port 8000）← 不需對外暴露

 每日啟動步驟
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  步驟 1：啟動後端
    cd C:\Users\User\stock-advisor
    python api_main.py

  步驟 2：啟動前端（另開終端機）
    cd C:\Users\User\stock-advisor-web
    npm run dev

  步驟 3：開啟 Claude Code（在 stock-advisor 目錄）
    → CLAUDE.md 會自動建立分析排程，無需手動操作

  步驟 4：開啟瀏覽器
    http://localhost:3000

  ── 外網連線（可選）──────────────────────────────────────────

  步驟 5：啟動 Cloudflare Quick Tunnel（另開終端機）
    cloudflared tunnel --url http://localhost:3000

    → 取得臨時網址（格式：https://xxxx.trycloudflare.com）
    → 此網址可從手機或任何外部網路存取
    → 注意：每次重啟網址會改變（Quick Tunnel 特性）
    → 安全性：HTTPS 加密，無需帳號，流量僅限自己使用

 自動排程時間（台灣時間，週一至週五）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  15:00   台股掃描 + K 線圖生成          → api_main.py 自動執行
  17:00   台股 Claude 分析（含籌碼刷新） → Claude Code 自動執行（需開著）
            Step 0：刷新當日籌碼資料（三大法人）
            Step 1-3：逐股分析並儲存

  21:00   美股掃描 + K 線圖生成          → api_main.py 自動執行
  21:20   美股 Claude 分析               → Claude Code 自動執行（需開著）
  22:00   每日盤後總結                   → Claude Code 自動執行（需開著）
            讀取台股 + 美股所有個股 Claude 分析結果
            跨市場挑選精選標的並撰寫市場觀察
            儲存至 scan_results/daily_summary_YYYYMMDD.json
            前端掃描頁頂部「今日盤後總結」面板自動顯示

  ※ Claude Code 排程注意事項（重要）：
     · 排程類型：session-only（預設），關閉 Claude Code 對話即失效
     · 重新開啟 Claude Code 對話後，CLAUDE.md 會自動重建三個排程
     · 每次重新開啟對話都需要讓 CLAUDE.md 的初始化指令跑完
     · 若排程消失，只需重開對話即可（無需手動建立）
     · 排程自動到期：7 天後需重新開啟對話重建

  ── 如何確認排程是否存在 ─────────────────────────────────────
     在 Claude Code 中輸入：「目前有哪些排程？」
     或：「幫我列出 cron 排程」
     Claude 會列出目前有效的台股/美股分析排程

  ※ 週六、週日自動跳過掃描，不覆蓋上週五的資料

  📡 /scanner   每日掃描
────────────────────────────────────────────────────────────

  【大盤策略狀態列（頁面頂端）】

  每次開啟掃描頁自動顯示，幫助判斷當日是否符合進場條件：

  · 加權指數（^TWII）三重ST狀態
    - 綠點數量（0~3）
  · S&P500（^GSPC）三重ST狀態
    - 綠點數量（0~3）
  · 月份旺季/淡季判斷
    - 旺季：10–4月（✓）
    - 淡季：5–9月（✗）
  · 綜合建議（台股用）：
    ✅ 策略全開－可積極進場（大盤3綠 + 旺季）
    ⚠️ 大盤強但淡季－謹慎進場
    🚫 條件不足－建議觀望

  【今日盤後總結面板（掃描結果 Tab 最頂部）】

  每日 22:00 由 Claude 自動生成，包含：
  · 今日台股精選：最值得關注的 1-3 支 BUY/WATCH，附選擇原因
  · 今日美股精選：最值得關注的 1-3 支 BUY/WATCH，附選擇原因
  · 需特別留意：財報近期警示、假突破風險高、建議跳過的股票
  · 今日市場觀察：台美股整體訊號品質與大方向
  面板可折疊，右上角顯示生成日期與時間

  【Tab 1：掃描結果】

  頂部控制列
  · 市場切換：台股 / 美股
  · 訊號篩選：全部 / BUY / WATCH / ✅策略符合
    「✅策略符合」= 大盤3綠 + 旺季，條件不達標時按鈕變灰
  · 掃描時間、股票總數、訊號數顯示
  · 手動觸發掃描按鈕（當天可立即重跑）

  掃描結果列表（每筆顯示）
  · 訊號標籤：BUY（綠）/ WATCH（黃）
  · 籌碼共振標籤（青色）：若同時出現在板塊流向買超前30名
  · WATCH升級標籤（紫色）：昨日 WATCH 今日升級 BUY（含連續天數）
  · 📅 財報近期標籤（橙色）：7 天內有財報，hover 顯示具體日期（美股為主）
  · 股票名稱（含中文名稱，台股）、代號、板塊
  · 收盤價、漲跌幅、RSI、量比
  · 觸發原因（例：三重SuperTrend翻多、量能放大...）
  · 趨勢分數（Trend Score）、進場評分（Entry Score）
  ※ 靜態 SL/TP/RR 已移除（3ST 為動態止損，固定數字無意義）
     止損位請參考 Claude 分析中的【操作建議】段落

  展開個股（點擊展開）
  ┌─ 左：Claude 技術分析
  │   BUY  → 【狀態診斷】/ 【支撐壓力分析】/ 【操作建議】（進場/止損/止盈）
  │           / 【持倉管理】/ 【進場時機評估】（🟢🟡🔴）
  │   WATCH → 【目前缺口】/ 【翻多可能性】（高/中/低）/ 【翻多條件】/ 【失敗風險】
  │
  └─ 右：K 線圖（15 日，輕量圖表）

  【Tab 2：訊號追蹤】

  開倉部位
  · 每筆 BUY 訊號自動加入追蹤
  · 進場價 = 訊號「次日開盤價」（策略設計為訊號日收盤確認、次日開盤買進）。新訊號先標示
    「⏳ 待次日開盤進場」，開盤價出現後才改寫進場價並重算加碼點位；待進場部位不計入績效
  · 出場同樣是「訊號日收盤確認 → 次日開盤賣出」：出場條件成立當天先標示
    「⏳ 待次日開盤出場」，部位續掛在持倉中（未實現損益以訊號日收盤暫估），次日開盤價
    出現後才以開盤價平倉並記錄；出場訊號日與實際成交日/價都會保留
  · 所有損益（含未實現）皆已扣來回成本：台股 0.585%（手續費 0.1425%×2 + 證交稅 0.3%）、
    美股 0.1%（沿用回測頁的保守估計）；未實現視為「若現在出場」的淨損益
  · 績效摘要另提供「含未實現（盯市）」統計：已平倉只會是停損出場的虧損單（獲利單續抱不平倉），
    單看已實現會系統性偏向虧損；勝率只計有漲跌的部位
  · 顯示：股票 / 板塊 / 進場日期 / 持倉天數 / 進場價 / 目前價格 / 未實現損益%
  · 當日止損：三條 ST 支撐線最高值，每次掃描後自動更新（動態）
  · ST多方 N/3：目前仍為多方的 ST 條數（3=全綠/2=警戒/下同）
  · ⚠️ ST 警戒 badge（黃色閃爍）：green_count 降至 2，接近觸發出場條件
  · 加碼計畫：以進場當時的風險單位（R = 進場價 − 訊號當時止損）規劃
    +1R / +2R 兩個加碼點位，金字塔式（首倉50%、加碼各30%/20%），
    每次加碼後停損同步上移，達到的加碼點會標示 ✅。屬進場當下的
    靜態規劃，不隨「當日止損」每日更新
  · 可手動關倉（記錄為已實現）
  ※ 止盈（TP）已移除顯示，策略以 ST 翻空為出場依據

  已結倉部位
  · 顯示所有歷史結倉紀錄
  · 欄位：進出場日期 / 進出場價格 / 損益% / 出場原因 / 持有天數
  · 出場原因顏色：
    紅色 = ST翻空類（三條ST全翻空 / ST翻空跌破進場價）
    黃色 = 手動出場
    灰色 = 其他

  績效摘要
  · 總交易次數 / 勝率 / 平均損益% / 累計損益%
  · 最佳交易 / 最差交易（含日期）
  · 平均持有天數
  · 目前開倉數 / 未實現損益%

  🪙 /crypto    加密貨幣訊號
────────────────────────────────────────────────────────────

  支援幣種：BTC / ETH / SOL / BNB / XRP / DOGE / ADA / AVAX / LINK（共 9 幣）
  資料來源：Binance 永續合約（fapi.binance.com）
  自動刷新：每 15 分鐘，倒數計時顯示於標題列

  ── Tab 1：策略訊號（預設）──

  各幣種套用各自最佳化策略的即時進場訊號（per-coin 最佳化）

  卡片訊號狀態：
  · 🟢 進場訊號  — 策略條件剛觸發（本根），現在可考慮進場
  · 趨勢延續中  — 訊號先前已觸發，趨勢仍在但進場時機已過
  · 等待中      — 策略條件尚未達成

  各策略指標顯示（依幣種不同）：
  · VB（BTC / XRP / LINK）
    ATR 收縮進度條（X/N 根）/ 收縮區間上下軌 / ATR 比率
    有訊號時：進場 / SL / TP 三格
  · 3ST（ETH）
    三條 SuperTrend 方向箭頭（↑多 / ↓空）/ 多頭條數（N/3）
  · EMA（SOL / BNB / DOGE / ADA）
    快線/慢線交叉狀態 + EMA 趨勢線（EMA200）
    黃金交叉提示 / EMA 間距% / 上次交叉幾根前
  · DC（AVAX）
    距 N 根高點百分比（進度條）/ N 根高點價位

  趨勢過濾標記（BTC / ETH）：
  · 日線 EMA200：✓ 多頭區間 / ✗ 空頭區間（不進場）

  展開 K 線圖（點擊卡片底部「▼ 展開 K 線圖」）：
  · EMA 策略：快線（藍）/ 慢線（橙）/ 趨勢線（灰）+ 綠箭頭標進場點
  · 3ST 策略：K 棒依多頭條數上色（綠=3條/黃=2條/橙=1條/紅=0條）+ 進場箭頭
  · VB 策略：琥珀色=ATR收縮中 + 進場箭頭
  · DC 策略：唐奇安通道高低線 + 進場箭頭
  ※ 進場箭頭（▲）= 最近一次策略訊號觸發時間點

  ※ 舊版 VB 總覽 / VB 詳細 Tab 已移除，頁面只保留策略訊號 Grid

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  策略名稱：三重 SuperTrend 由紅轉綠
  三組參數：(period=11, mult=2.0) / (period=10, mult=1.0) / (period=12, mult=3.0)

  核心邏輯：只追蹤「當天剛發生翻多」的股票
    BUY  → 三條今日全翻多（green_count==3 AND prev_green<3）三條全綠才觸發
    WATCH → 今日達到 2/3 多方（green_count==2 AND prev_green<2）剛新增一條翻多
    WAIT  → 持續多頭或持續整理 → 不出現在清單中

  目的：避免堆積大量持續多頭標的，每天只顯示「剛翻多」的機會

  WATCH 翻多難易度參考：
    剩 ST(11,2.0) 未翻 → 中等靈敏度，相對容易翻多
    剩 ST(10,1.0) 未翻 → 最敏感參數，偶爾出現
    剩 ST(12,3.0) 未翻 → 最寬幅參數，需較大漲幅，最難翻

  Claude 分析格式（claude_scanner_analysis.py）：
    BUY  → 【狀態診斷】/ 【支撐壓力分析】/ 【操作建議】（進場/止損/止盈）
            / 【持倉管理】/ 【進場時機評估】（🟢立即進場/🟡等回踩/🔴觀望）
    WATCH → 【目前缺口】/ 【翻多可能性】（高/中/低）/ 【翻多所需條件】/ 【失敗風險】

  Claude 分析輸入資料（每支股票皆包含）：
    · 近 15 根 OHLCV（含相對量比，量比 = 當日量 / 均量）
    · 市場狀態 regime（多頭 / 整理 / 弱勢）
    · 台股：公司中文名稱（TWSE/TPEX 官方）
    · 台股：當日三大法人買超資訊（外資/投信，排名，籌碼共振判斷）
    · 台股：融資融券數據（融資餘額/今日增減，融券餘額/今日增減）
    · 近 5 天歷史訊號脈絡（例：09/17 WATCH → 09/18 WATCH → 09/19 BUY）
    · entry_score（進場評分）/ trend_score（趨勢分數）
    · 【歷史回測績效】該股 2021–2026 三重ST翻多統計：
      觸發次數 / 勝率 / 期望值 / 平均獲利 / 平均虧損 / 平均持倉天數
      信號品質評級：優（EV>5%）/ 良（>2%）/ 普通（>0%）/ 偏差（<0%）
      讓 Claude 能根據歷史表現給出差異化建議，而非每支說法相近

    ── 假訊號辨識與過濾（2026-10-03，false_signal_analysis.py / filter_eval.py）──
    假訊號 = 持有 <=14 天且虧損：占 14%，平均 -8.7%（其餘交易 +3.8%）。
    以訓練期（進場 2021–2024）決定五分位切點、驗證期（2025–2026）檢驗，只採信兩期方向一致且顯著者：
      量比最高 20%（>4.6 倍）    假訊號率 18.7% / 22.1%（最低 20% 為 13.6% / 12.7%）
      訊號日漲幅最高 20%（>8.6%） 假訊號率 19.0% / 20.2%（最低 20% 為 11.5% / 12.8%）
      距 52 週高點越近           超額報酬越高（最近 vs 最遠 20%：+3.8 / +4.4，兩期皆顯著）
      RSI、ATR、距 52 週低、股價、近 5/20 日漲幅、乖離 → 兩期結論不一致，不採信
    規則的樣本外驗證（台股，扣成本，等權重組合近似；全市場 Sharpe 訓練 1.52 / 驗證 1.32）：
      R2+R3 濾掉量比暴增與訊號日大漲（保留 67–69%）：
          Sharpe 0.72→1.02（訓練）、0.94→1.19（驗證）；最大回撤 -25.6%→-18.8%、-21.4%→-19.5%
      R1+R2+R3 再加「近 52 週高前 40%」（保留 29% / 16%）：Sharpe 1.59 / 1.40，超額每筆 +1.5% / +2.4%
          年化 alpha +2.5% / +6.1%（不顯著）
    但：R1 的效果主要是「52 週高點動能」因子本身。同條件下隨機挑接近 52 週高點的股票，持有期平均
    +3.52%（訓練）/ +2.39%（驗證），訊號僅多 +0.28% [-0.41,+0.98] / +1.75% [+0.38,+3.13]（全期 +0.60%，t≈1.9）。
    解讀：量比/漲幅過濾確實降低假訊號並改善淨績效；近高點過濾有效，但不應全部歸功於三重ST訊號。
    尚未套用到即時掃描器。
    執行：python false_signal_analysis.py；python filter_eval.py

  ── 4 種策略（回測期 2023-2026，8-9 幣種） ──

  VB  波動率收縮突破（Volatility Breakout）
  · 時框：1H
  · 收縮：ATR(14) < ATR_MA(50) × 閾值，連續 ≥ N 根
  · 進場：收縮結束後收盤突破上軌做多

  3ST 三重 SuperTrend
  · 時框：4H
  · 參數：(11,2.0) / (10,1.0) / (12,3.0)
  · 進場：三條 ST 全部翻多（可設 long_only）
  · 出場：任一條翻空

  EMA EMA 快慢線交叉 + 趨勢過濾
  · 時框：4H
  · 進場：快線（fast EMA）黃金交叉慢線（slow EMA）+ 收盤 > 趨勢線（EMA N）
  · 止損：固定百分比

  DC  唐奇安通道突破（Donchian Channel）
  · 時框：4H
  · 進場：收盤突破 N 根高點
  · 出場：跌破 M 根低點或止損

  ── Per-coin 最佳化配置（COIN_BEST）──

  各幣種套用回測表現最佳的策略與參數：
  BTC  → VB  (atr_thresh=0.9,  sq=20, tp=1.0) + 日線EMA200過濾
  ETH  → 3ST (long_only, sl=8%) + 日線EMA200過濾
  SOL  → EMA (12/26, trend=200, stop=7%)
  BNB  → EMA (9/21,  trend=200, stop=5%)
  XRP  → VB  (atr_thresh=0.8,  sq=10, tp=1.0)
  AVAX → DC  (entry=10, exit=7, stop=6%)
  DOGE → EMA (7/21,  trend=100, stop=7%)
  LINK → VB  (atr_thresh=0.75, sq=15, tp=1.0)
  ADA  → EMA (9/26,  trend=200, stop=7%)

  日線 EMA200 大趨勢過濾（BTC / ETH 限定）：
  · 收盤 > 日線 EMA200 → 多頭區間，允許進場
  · 收盤 < 日線 EMA200 → 空頭區間，暫不進場
  · 效果：2021-2022 熊市 BTC 從 -35% 改善至 -19%

  A：排程是 session-only，關掉對話就會消失。
     解法：重新開啟 Claude Code 對話（在 stock-advisor 目錄下）
     CLAUDE.md 會在對話開始時自動重建台股（17:00）和美股（21:20）排程
     確認方式：在 Claude Code 說「目前有哪些排程？」

  Q：想立即看今天的分析怎麼辦？
  A：在 Claude Code 說：
     「幫我分析今天的台股掃描結果」或
     「幫我分析今天的美股掃描結果」
     Claude 會立即讀取資料並寫入分析，不需要等排程

  Q：手機用外網連進來掃描頁顯示「載入失敗」？
  A：最常見原因是 .env.local 設了 NEXT_PUBLIC_API_URL=http://localhost:8000
     手機瀏覽器收到後會直接打手機自己的 localhost，當然連不到
     解法：清空 .env.local，重啟 npm run dev，讓 API 走相對路徑由 Next.js proxy 轉發

  Q：Cloudflare Tunnel 網址每次都不一樣？
  A：Quick Tunnel（免帳號）每次重啟網址會改變，屬正常現象
     若需固定網址，需申請 Cloudflare 帳號並建立 Named Tunnel

  Q：板塊資金流向的累計模式數字跟單日一樣？
  A：舊快照（未含個股 stocks 欄位）會自動觸發重抓，重啟後端後再重新整理即可
     若仍有問題，刪除 sector_flow_data/ 目錄下的舊 JSON 檔，讓系統重新抓取

  Q：板塊流向頁面抓不到資料？
  A：TWSE T86 每天收盤後約 18:00 才更新，盤中請求會回傳前一交易日資料
     週末請求自動回退至上週五資料

  Q：美股板塊流向顯示 HTTP 404？
  A：後端未重啟即生效新路由。停止並重啟 api_main.py 即可

  Q：掃描頁的「籌碼共振」標記是什麼？
  A：每次載入掃描頁時，自動抓取當日台股板塊流向，取所有個股依三大合計排序
     前 30 名存為清單。若 BUY/WATCH 股票同時在此清單中，即顯示「籌碼共振」
     代表技術面翻多且籌碼面同步流入，為雙重共振訊號

  Q：掃描頁頂端的大盤狀態是什麼？
  A：每次開啟掃描頁時自動呼叫 /api/scanner/market-state，
     即時計算加權指數（^TWII）和 S&P500（^GSPC）的三重ST方向。
     顯示三個綠/紅點代表三條ST的多空狀態，並判斷當月是否為旺季（10–4月）。
     綜合條件：大盤3綠 + 旺季 = ✅ 策略全開，才是最佳進場環境。
     研究結論：大盤3綠過濾可將期望值從 +2.0% 提升至 +3.9%

  Q：「✅策略符合」過濾按鈕是什麼？
  A：只顯示當日大盤3綠 + 旺季條件下的 BUY 訊號。
     條件不達標時按鈕變灰（disabled）。
     此條件並非強制，在大盤未達標時仍可查看全部訊號自行判斷。

  Q：Claude 分析裡的【歷史回測績效】是什麼？
  A：從 backtest_results/ 的回測 CSV 自動計算該股 2021–2026 年間
     三重ST翻多訊號的歷史統計（觸發次數/勝率/期望值/平均損益/持倉天數），
     讓 Claude 能根據這支股票的歷史表現給出差異化分析，
     而非對所有股票說法相近。需先執行過 backtest_portfolio.py 才有資料。

  Q：掃描頁的進場時機標籤（🟢🟡🔴）是怎麼來的？
  A：由 Claude 在分析時在【進場時機評估】段落給出明確判斷
     · 🟢 立即進場：今日翻多且量能配合，追價風險低
     · 🟡 等回踩：近期已有一段漲幅，建議等拉回 ST 支撐附近再進
     · 🔴 觀望：動能不足或走勢疑慮，暫不介入
     前端自動解析此段落並顯示對應顏色標籤（僅 BUY 訊號顯示）
     ※ 注意：回測研究顯示進場時機標籤未經過驗證，僅供參考

  Q：板塊流向頁的「BUY/WATCH」標記是什麼？
  A：頁面載入時抓取當日台股掃描結果，若個股同時有 BUY 或 WATCH 訊號，
     在前十名排行及展開個股明細中顯示對應標記

  Q：連買 / 連賣天數是怎麼算的？
  A：回溯最近 20 個交易日快照，從最新那天往前找連續同方向天數
     ≥ 2 天才顯示標籤，避免單日噪音。快照不足 20 天時以現有資料計算

  Q：美股板塊流向和台股有何不同？
  A：台股使用三大法人官方買賣超張數（每日更新）
     美股沒有對等頻率的機構資料，改用 11 支 SPDR 板塊 ETF
     相對 SPY 的報酬率作為資金輪動代理指標，量比輔助確認動能

  Q：加密貨幣頁面看到「X 個訊號觸發」但不確定是哪幣？
  A：切換到「總覽」模式，所有幣的狀態一目了然
     有訊號的幣卡片會顯示做多/做空入場標籤（綠/紅邊框）

  Q：回測頁要怎麼輸入台股代號？
  A：選擇市場後直接輸入數字代號，不需手動加後綴
     台股上市選「台股上市(.TW)」→ 輸入 2330 → 自動補成 2330.TW
     台股上櫃選「台股上櫃(.TWO)」→ 輸入 6547 → 自動補成 6547.TWO

  Q：為什麼今天有些股票沒有 Claude 分析？
  A：Claude 分析對所有 BUY + WATCH 股票全數進行，不設上限
     若個別股票缺少，在 Claude Code 說「幫我分析今天的台股掃描結果」手動補齊

  Q：週末手動觸發掃描有用嗎？
  A：不會執行，系統會自動偵測週六/日並跳過掃描
     這樣可以避免用空白結果覆蓋週五的好資料

  Q：Claude 分析裡的融資融券數據是什麼時候的？
  A：TWSE MI_MARGN API 當日資料約在 16:00 後更新，
     因此 Claude 分析排程設在 17:00，確保抓到當天最新融資融券數據。
     若 17:00 前手動執行分析，融資融券可能仍是前一交易日資料。

  Q：intraday_snapshots 資料夾有什麼用？
  A：每次 BUY 訊號開倉時自動儲存當日 5m/15m/30m K 棒，
     用於未來驗證「進場當天開盤確認」是否有效。
     回測顯示進場日收紅的 EV 是收黑的 6 倍（+5.04% vs -0.52%），
     累積幾個月的日內數據後可做正式統計驗證。

  Q：訊號追蹤的出場邏輯從什麼時候改變的？
  A：2026-09-25 改為三重 ST 翻空規則，取代原本的「訊號消失就關倉」。
     舊邏輯：掃描器隔天看不到該股就關倉（因為掃描器只顯示當天剛翻多的股票）
     新邏輯：每次掃描後重新計算開倉部位的 green_count，
     依 ST 翻空 + 跌破進場價的條件決定是否出場，部位可持續多天追蹤

  Q：持倉列表的「⚠️ ST 警戒」是什麼意思？
  A：目前持倉的三條 ST 中已有一條翻空（green_count = 2），
     若當日收盤跌破進場價則觸發出場，尚未出場代表目前仍在進場價以上。
     此時應密切關注，下一條翻空若仍高於進場價則繼續持有。

  Q：掃描結果的「📅 財報近期」是什麼？
  A：該股票 7 天內有財報公布，hover 可看具體日期。
     財報前後波動大，即使 ST 翻多也可能是一次性反應，建議謹慎。
     主要對美股有效（yfinance 財報日覆蓋較完整），台股通常不顯示。

  Q：每日總結沒有出現在掃描頁？
  A：可能原因：
     1. 22:00 排程時 Claude Code 未開著
     2. 台美股分析都尚未完成（prompt 讀不到資料回傳空字串）
     → 手動觸發：在 Claude Code 說「幫我產生今天的盤後總結」
     → Claude 會讀取兩市場分析結果並撰寫，儲存後前端自動顯示
