  [FastAPI 後端]  python api_main.py       → http://localhost:8000
  [前端介面]      npm run dev              → http://localhost:3000
  [Claude 分析]   Claude Code 開著即可     → 排程自動執行

  資料流向：
  api_main.py（掃描 + K 線圖生成）→ scan_results/tw_日期.json
                                      ↓
  Claude Code（分析，17:00/21:20）  → scan_results/claude_tw_日期.json
                                      ↓
  API /api/scanner/results            → 合併兩份，回傳前端
                                      ↓
  前端 /scanner 頁                    → 展開個股：
                                          左：Claude 分析
                                          右：K 線圖

  外網架構（Cloudflare Tunnel）：
  手機/外部裝置
    → Cloudflare Tunnel（https://xxxx.trycloudflare.com）
    → Next.js（port 3000）← 只需暴露這一個 port
    → Next.js rewrite proxy（/api/* → localhost:8000）
    → FastAPI（port 8000）← 不需對外暴露

  步驟 1：啟動後端
    cd C:\Users\User\stock-advisor
    python api_main.py

  步驟 2：啟動前端（另開終端機）
    cd C:\Users\User\stock-advisor-web
    npm run dev

  步驟 3：開啟 Claude Code（在 stock-advisor 目錄）
    → CLAUDE.md 會自動建立分析排程，無需手動操作

  步驟 4：開啟瀏覽器
    http://localhost:3000

  ── 外網連線（可選）──────────────────────────────────────────

  步驟 5：啟動 Cloudflare Quick Tunnel（另開終端機）
    cloudflared tunnel --url http://localhost:3000

    → 取得臨時網址（格式：https://xxxx.trycloudflare.com）
    → 此網址可從手機或任何外部網路存取
    → 注意：每次重啟網址會改變（Quick Tunnel 特性）
    → 安全性：HTTPS 加密，無需帳號，流量僅限自己使用

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  15:00   台股掃描 + K 線圖生成          → api_main.py 自動執行
  17:00   台股 Claude 分析（含籌碼刷新） → Claude Code 自動執行（需開著）
            Step 0：刷新當日籌碼資料（三大法人）
            Step 1-3：逐股分析並儲存

  21:00   美股掃描 + K 線圖生成          → api_main.py 自動執行
  21:20   美股 Claude 分析               → Claude Code 自動執行（需開著）

  ※ Claude Code 排程注意事項（重要）：
     · 排程類型：session-only（預設），關閉 Claude Code 對話即失效
     · 重新開啟 Claude Code 對話後，CLAUDE.md 會自動重建排程
     · 每次重新開啟對話都需要讓 CLAUDE.md 的初始化指令跑完
     · 若排程消失，只需重開對話即可（無需手動建立）

  ── 如何確認排程是否存在 ─────────────────────────────────────
     在 Claude Code 中輸入：「目前有哪些排程？」
     或：「幫我列出 cron 排程」
     Claude 會列出目前有效的台股/美股分析排程

  ※ 週六、週日自動跳過掃描，不覆蓋上週五的資料

  📡 /scanner   每日掃描
────────────────────────────────────────────────────────────

  【大盤策略狀態列（頁面頂端）】

  每次開啟掃描頁自動顯示，幫助判斷當日是否符合進場條件：

  · 加權指數（^TWII）三重ST狀態
    - 綠點數量（0~3）
  · S&P500（^GSPC）三重ST狀態
    - 綠點數量（0~3）
  · 月份旺季/淡季判斷
    - 旺季：10–4月（✓）
    - 淡季：5–9月（✗）
  · 綜合建議（台股用）：
    ✅ 策略全開－可積極進場（大盤3綠 + 旺季）
    ⚠️ 大盤強但淡季－謹慎進場
    🚫 條件不足－建議觀望

  【Tab 1：掃描結果】

  頂部控制列
  · 市場切換：台股 / 美股
  · 訊號篩選：全部 / BUY / WATCH / ✅策略符合
    「✅策略符合」= 大盤3綠 + 旺季，條件不達標時按鈕變灰
  · 掃描時間、股票總數、訊號數顯示
  · 手動觸發掃描按鈕（當天可立即重跑）

  掃描結果列表（每筆顯示）
  · 訊號標籤：BUY（綠）/ WATCH（黃）
  · 籌碼共振標籤（青色）：若同時出現在板塊流向買超前30名
  · WATCH升級標籤（紫色）：昨日 WATCH 今日升級 BUY（含連續天數）
  · 股票名稱（含中文名稱，台股）、代號、板塊
  · 收盤價、漲跌幅、RSI、量比
  · 觸發原因（例：三重SuperTrend翻多、量能放大...）
  · 趨勢分數（Trend Score）、進場評分（Entry Score）

  展開個股（點擊展開）
  ┌─ 左：Claude 技術分析
  │   BUY  → 【狀態診斷】/ 【支撐壓力分析】/ 【操作建議】（進場/止損/止盈）
  │           / 【持倉管理】/ 【進場時機評估】（🟢🟡🔴）
  │   WATCH → 【目前缺口】/ 【翻多可能性】（高/中/低）/ 【翻多條件】/ 【失敗風險】
  │
  └─ 右：K 線圖（15 日，輕量圖表）

  開倉部位

  · 顯示：股票 / 板塊 / 進場日期 / 進場價 / 目前價格 / 未實現損益%
  · 顯示：止損 / 止盈 / 風報比

  ── 詳細模式 ──

  頂部幣種快覽列（8 個按鈕，顯示各幣訊號狀態）

  大型訊號卡
  · 幣名 / 全名 / 目前價格
  · 訊號標籤（做多入場 / 做空入場 / 等待訊號）+ 風報比

  有訊號時顯示入場詳情（3 格）
  · 進場價 / 止損 SL（含百分比）/ 目標 TP（含百分比）

  15m K 線圖（lightweight-charts）
  · K 棒（綠漲 / 紅跌，收縮中以琥珀色標示）
  · EMA20（藍線）/ EMA50（紫線）
  · 收縮上下軌（橙色虛線）
  · 止損 / 止盈線（有訊號時，紅/綠實線）
  · 4H EMA20 / EMA50（藍/紫虛線，作為水平參考）

  策略邏輯三步驟（VB 說明）
  · 步驟1：ATR 波動率收縮（≥20根，比率<0.75）
  · 步驟2：4H 趨勢過濾（EMA20 vs EMA50）
  · 步驟3：突破觸發入場（收盤突破上/下軌）
  · 每步顯示：達標 / 等待中 + 目前數值

  止損止盈邏輯說明
  · LONG SL = 收縮下軌（最大 -5%）/ SHORT SL = 收縮上軌
  · TP = 進場價 ± 收縮幅度 × 1.5

  收縮觀察區間（WAIT 且有收縮時）
  · 上軌（突破做多）/ 下軌（跌破做空）

  指標面板（4 格）
  · ATR 收縮進度（X/20 根，進度條）
  · 4H 趨勢（↑上升 / ↓下降 + EMA 數值）
  · ATR 比率（數值 + 進度條，門檻 < 0.75）
  · 收縮區間幅度（百分比 + 上下軌數值）

 掃描策略說明（signal_engine.py）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  策略名稱：三重 SuperTrend 由紅轉綠
  三組參數：(period=11, mult=2.0) / (period=10, mult=1.0) / (period=12, mult=3.0)

  核心邏輯：只追蹤「當天剛發生翻多」的股票
    BUY  → 三條今日全翻多（green_count==3 AND prev_green<3）三條全綠才觸發
    WATCH → 今日達到 2/3 多方（green_count==2 AND prev_green<2）剛新增一條翻多
    WAIT  → 持續多頭或持續整理 → 不出現在清單中

  目的：避免堆積大量持續多頭標的，每天只顯示「剛翻多」的機會

  WATCH 翻多難易度參考：
    剩 ST(11,2.0) 未翻 → 中等靈敏度，相對容易翻多
    剩 ST(10,1.0) 未翻 → 最敏感參數，偶爾出現
    剩 ST(12,3.0) 未翻 → 最寬幅參數，需較大漲幅，最難翻

  Claude 分析格式（claude_scanner_analysis.py）：
    BUY  → 【狀態診斷】/ 【支撐壓力分析】/ 【操作建議】（進場/止損/止盈）
            / 【持倉管理】/ 【進場時機評估】（🟢立即進場/🟡等回踩/🔴觀望）
    WATCH → 【目前缺口】/ 【翻多可能性】（高/中/低）/ 【翻多所需條件】/ 【失敗風險】

  Claude 分析輸入資料（每支股票皆包含）：
    · 近 15 根 OHLCV（含相對量比，量比 = 當日量 / 均量）
    · 市場狀態 regime（多頭 / 整理 / 弱勢）
    · 台股：公司中文名稱（TWSE/TPEX 官方）
    · 台股：當日三大法人買超資訊（外資/投信，排名，籌碼共振判斷）
    · 台股：融資融券數據（融資餘額/今日增減，融券餘額/今日增減）
    · 近 5 天歷史訊號脈絡（例：09/17 WATCH → 09/18 WATCH → 09/19 BUY）
    · entry_score（進場評分）/ trend_score（趨勢分數）
    · 【歷史回測績效】該股 2021–2026 三重ST翻多統計：
      觸發次數 / 勝率 / 期望值 / 平均獲利 / 平均虧損 / 平均持倉天數
      信號品質評級：優（EV>5%）/ 良（>2%）/ 普通（>0%）/ 偏差（<0%）
      讓 Claude 能根據歷史表現給出差異化建議，而非每支說法相近

  融資融券資料來源：
    TWSE MI_MARGN API（T day 資料，約 16:00 後更新）
    因此台股 Claude 分析排程設在 17:00，確保數據已更新

  執行方式（不需啟動後端）：

    結算：回測結束日仍持倉 → 當日收盤價結算
    手續費：台股買入 0.1425%，賣出 0.1425% + 0.3%（交易稅）

  回測研究結論（台股 2021–2026，1979支）：

    策略條件                 筆數     勝率    期望值
    ─────────────────────────────────────────────
    無過濾                  37,733   35.8%   +1.99%
    大盤>=1綠               23,330   37.8%   +2.92%
    大盤3綠                  9,926   39.8%   +3.90%
    大盤3綠 + 避5–9月       16,133   39.3%   +3.73%  ← 日常進場參考
    大盤3綠 + 只做10–4月     5,844   41.4%   +4.88%  ← 最嚴格篩選

    量比過濾：無效（高量比反而更差，高量比=追漲爆量，翻多後易回跌）
    ML模型預測：無效（AUC≈0.50，技術特徵無法預測個股勝負）
    有效過濾：大盤ST狀態（最顯著）+ 季節性（輔助）

    進場當天確認（日 K proxy，37,733 筆）：
    · 進場日收紅（close > open）：44.0% WR，+5.04% EV  ← 強過濾效果
    · 進場日收黑：29.5% WR，-0.52% EV
    · 進場日漲幅 > 3%：50.4% WR，+9.04% EV
    日內 K 棒快照已於每次 BUY 訊號時自動儲存（見「訊號追蹤器」章節）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  策略名稱：VB 波動率收縮突破（Volatility Breakout）
  資料來源：Binance 永續合約（fapi.binance.com）
  時框：15m K 線 + 4H 趨勢

  收縮條件：ATR(14) < ATR_MA(50) × 0.75，連續 ≥ 20 根
  突破進場：
    LONG  → 收盤突破收縮上軌 + 4H EMA20 > EMA50
    SHORT → 收盤跌破收縮下軌 + 4H EMA20 < EMA50
  止損：max(收縮下軌, 現價 × 95%)
  止盈：現價 + 收縮幅 × 1.5

 常見問題
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Q：展開個股沒有 Claude 分析？
  A：可能原因：
     1. Claude Code 在 17:00 / 21:20 時沒有開著
     2. 當天掃描沒有 BUY/WATCH 訊號
     → 手動觸發：在 Claude Code 說「幫我分析今天的台股掃描結果」

  Q：掃描頁顯示舊資料？
  A：api_main.py 沒有在跑，重新啟動即可

  Q：Claude Code 排程消失了怎麼辦？
  A：排程是 session-only，關掉對話就會消失。
     解法：重新開啟 Claude Code 對話（在 stock-advisor 目錄下）
     CLAUDE.md 會在對話開始時自動重建台股（17:00）和美股（21:20）排程
     確認方式：在 Claude Code 說「目前有哪些排程？」

  Q：想立即看今天的分析怎麼辦？
  A：在 Claude Code 說：
     「幫我分析今天的台股掃描結果」或
     「幫我分析今天的美股掃描結果」
     Claude 會立即讀取資料並寫入分析，不需要等排程

  Q：手機用外網連進來掃描頁顯示「載入失敗」？
  A：最常見原因是 .env.local 設了 NEXT_PUBLIC_API_URL=http://localhost:8000
     手機瀏覽器收到後會直接打手機自己的 localhost，當然連不到
     解法：清空 .env.local，重啟 npm run dev，讓 API 走相對路徑由 Next.js proxy 轉發

  Q：Cloudflare Tunnel 網址每次都不一樣？
  A：Quick Tunnel（免帳號）每次重啟網址會改變，屬正常現象
     若需固定網址，需申請 Cloudflare 帳號並建立 Named Tunnel

  Q：板塊資金流向的累計模式數字跟單日一樣？
  A：舊快照（未含個股 stocks 欄位）會自動觸發重抓，重啟後端後再重新整理即可
     若仍有問題，刪除 sector_flow_data/ 目錄下的舊 JSON 檔，讓系統重新抓取

  Q：板塊流向頁面抓不到資料？
  A：TWSE T86 每天收盤後約 18:00 才更新，盤中請求會回傳前一交易日資料
     週末請求自動回退至上週五資料

  Q：美股板塊流向顯示 HTTP 404？
  A：後端未重啟即生效新路由。停止並重啟 api_main.py 即可

  Q：掃描頁的「籌碼共振」標記是什麼？
  A：每次載入掃描頁時，自動抓取當日台股板塊流向，取所有個股依三大合計排序
     前 30 名存為清單。若 BUY/WATCH 股票同時在此清單中，即顯示「籌碼共振」
     代表技術面翻多且籌碼面同步流入，為雙重共振訊號

  Q：掃描頁頂端的大盤狀態是什麼？
  A：每次開啟掃描頁時自動呼叫 /api/scanner/market-state，
     即時計算加權指數（^TWII）和 S&P500（^GSPC）的三重ST方向。
     顯示三個綠/紅點代表三條ST的多空狀態，並判斷當月是否為旺季（10–4月）。
     綜合條件：大盤3綠 + 旺季 = ✅ 策略全開，才是最佳進場環境。
     研究結論：大盤3綠過濾可將期望值從 +2.0% 提升至 +3.9%

  Q：「✅策略符合」過濾按鈕是什麼？
  A：只顯示當日大盤3綠 + 旺季條件下的 BUY 訊號。
     條件不達標時按鈕變灰（disabled）。
     此條件並非強制，在大盤未達標時仍可查看全部訊號自行判斷。

  Q：Claude 分析裡的【歷史回測績效】是什麼？
  A：從 backtest_results/ 的回測 CSV 自動計算該股 2021–2026 年間
     三重ST翻多訊號的歷史統計（觸發次數/勝率/期望值/平均損益/持倉天數），
     讓 Claude 能根據這支股票的歷史表現給出差異化分析，
     而非對所有股票說法相近。需先執行過 backtest_portfolio.py 才有資料。

  Q：掃描頁的進場時機標籤（🟢🟡🔴）是怎麼來的？
  A：由 Claude 在分析時在【進場時機評估】段落給出明確判斷
     · 🟢 立即進場：今日翻多且量能配合，追價風險低
     · 🟡 等回踩：近期已有一段漲幅，建議等拉回 ST 支撐附近再進
     · 🔴 觀望：動能不足或走勢疑慮，暫不介入
     前端自動解析此段落並顯示對應顏色標籤（僅 BUY 訊號顯示）
     ※ 注意：回測研究顯示進場時機標籤未經過驗證，僅供參考

  Q：板塊流向頁的「BUY/WATCH」標記是什麼？
  A：頁面載入時抓取當日台股掃描結果，若個股同時有 BUY 或 WATCH 訊號，
     在前十名排行及展開個股明細中顯示對應標記

  Q：連買 / 連賣天數是怎麼算的？
  A：回溯最近 20 個交易日快照，從最新那天往前找連續同方向天數
     ≥ 2 天才顯示標籤，避免單日噪音。快照不足 20 天時以現有資料計算

  Q：美股板塊流向和台股有何不同？
  A：台股使用三大法人官方買賣超張數（每日更新）
     美股沒有對等頻率的機構資料，改用 11 支 SPDR 板塊 ETF
     相對 SPY 的報酬率作為資金輪動代理指標，量比輔助確認動能

  Q：加密貨幣頁面看到「X 個訊號觸發」但不確定是哪幣？
  A：切換到「總覽」模式，所有幣的狀態一目了然
     有訊號的幣卡片會顯示做多/做空入場標籤（綠/紅邊框）

  Q：回測頁要怎麼輸入台股代號？
  A：選擇市場後直接輸入數字代號，不需手動加後綴
     台股上市選「台股上市(.TW)」→ 輸入 2330 → 自動補成 2330.TW
     台股上櫃選「台股上櫃(.TWO)」→ 輸入 6547 → 自動補成 6547.TWO

  Q：為什麼今天有些股票沒有 Claude 分析？
  A：Claude 分析對所有 BUY + WATCH 股票全數進行，不設上限
     若個別股票缺少，在 Claude Code 說「幫我分析今天的台股掃描結果」手動補齊

  Q：週末手動觸發掃描有用嗎？
  A：不會執行，系統會自動偵測週六/日並跳過掃描
     這樣可以避免用空白結果覆蓋週五的好資料

  Q：Claude 分析裡的融資融券數據是什麼時候的？
  A：TWSE MI_MARGN API 當日資料約在 16:00 後更新，
     因此 Claude 分析排程設在 17:00，確保抓到當天最新融資融券數據。
     若 17:00 前手動執行分析，融資融券可能仍是前一交易日資料。

  Q：intraday_snapshots 資料夾有什麼用？
  A：每次 BUY 訊號開倉時自動儲存當日 5m/15m/30m K 棒，
     用於未來驗證「進場當天開盤確認」是否有效。
     回測顯示進場日收紅的 EV 是收黑的 6 倍（+5.04% vs -0.52%），
     累積幾個月的日內數據後可做正式統計驗證。
